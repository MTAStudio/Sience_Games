بازی‌های علوم — راهنمای انتشار در GitHub Pages

محتویات:
- index.html: صفحه‌ی اصلی با طراحی Grid، انیمیشن، جست‌وجو و بخش رأی‌گیری
- games/: فایل‌های HTML بازی‌ها که از آرشیو استخراج شدند

لینک‌های آنلاین TXT:
- متقیان: https://mtastudio.github.io/Atomsaz_/ (در بالای صفحه قرار دارد)
- حسین زاده: https://survey.porsline.ir/s/piBLIW0m

فایل‌های کامپیوتری:
آرشیو اصلی شامل دو فایل بزرگ لطفعلی پور.rar و مختاریانی.rar است (حدود 90MB و 37MB). به‌دلیل محدودیت فایل 100MB در GitHub، این دو فایل در ZIP وب‌سایت قرار نگرفته‌اند. آن‌ها را از آرشیو اصلی جداگانه در GitHub Releases یا یک میزبان فایل قرار دهید و لینک‌های downloads/لطفعلی پور.rar و downloads/مختاریانی.rar را در index.html به آدرس مستقیم فایل‌ها تغییر دهید. این دو کارت با برچسب نسخه کامپیوتری نمایش داده می‌شوند.

رأی‌گیری: GitHub Pages بک‌اند ندارد. نسخه فعلی فقط با localStorage در همان مرورگر یک رأی را محدود می‌کند؛ این محدودیت IP نیست و با پاک‌کردن داده‌های مرورگر یا دستگاه دیگر قابل دور زدن است. برای محدودیت واقعی یک رأی به‌ازای IP، سرویس سمت سرور و پایگاه داده لازم است.
